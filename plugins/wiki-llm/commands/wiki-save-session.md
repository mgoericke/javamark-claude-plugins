# /wiki-save-session

Go through the whole conversation and find what is worth keeping.

1. Find the wiki and read its rules, as in `/wiki-save`.
2. Look for solved problems, decisions and their reasons, validated patterns, root causes, tool insights and surprises. Skip tool output, trivial exchanges and debugging noise.
3. Check `index.md` for each candidate. Mark it **update** if a page exists, **new** if not.
4. Present a numbered list and wait for the selection:

   ```
   ## Session learnings, YYYY-MM-DD

   1. [new, recipe] How to configure X: solution for Y with Z
   2. [update] wiki/concepts/blast-radius: new example from the migration
   3. [new, decision] Why A over B: the reasons at the time
   ```

5. For each selected item follow the SAVE workflow. Show the drafts together, then write after one approval.

If the session had nothing worth keeping, say so.
